# Joke

Tell the user one joke from the programming world. Draw from any technical domain — languages, bugs, version control, regex, off-by-one errors, recursion, CSS, build systems, etc. If the conversation has a clear technical theme (e.g. they've been debugging SQL or wrestling with Git), pick a joke from that domain.

Guidelines:
- Output just the joke. No preamble like "Here's a joke for you:" and no post-joke commentary like "Hope that made you smile!".
- The joke must be programming-related. No general-audience jokes.
- Keep it work-safe and inoffensive.
- Don't repeat a joke you've already told in this conversation.
- If the user asks for another, tell a different one in a different style than the last (e.g. switch from a one-liner to a pun, or from a language joke to a hardware joke).
